The public demo's sample (`LEAKTRACE_DEMO=1`): `lecture.mp4` is a synthetic 4-minute lecture (generated slides and
text-to-speech, no real course content). On the demo's first start the service packages it, adds 1,000 sample
accounts, and makes four sample leaks from named viewers' copies (Telegram, phone filming, cropped, screen-recorded),
tracing each once; the demo page shows them with a short guided tour. `bench.json` is the attack bench run on it,
shown on the Bench tab until the demo runs its own.
